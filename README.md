## v10 — 暫停按鈕 ＆ 得分/扣分公告系統
**變更類型：** 新功能

### 暫停系統
- 新增暫停按鈕（位於倒計時下方）
- 新增 `PAUSED` 遊戲狀態
- 鍵盤 `P` / `Escape` 鍵可切換暫停
- 暫停時 Canvas 繪製半透明覆蓋層

### 公告系統
- 新增 `ANNOUNCE` 遊戲狀態
- 得分事件後顯示 "Player/NPC Point +1"（持續 3 秒）
- 扣分事件後顯示 "Player/NPC Point -1"（持續 3 秒）
- 公告結束後自動進入 3 秒倒計時
- 公告文字帶有柔和脈動動畫效果

## v4 — AI 反衝/硬直機制
**變更類型：** 遊戲機制

- AI 被搶奪球體後進入反衝狀態（`recoilCD`）：
  - 硬直期 0.85 秒，期間以低速（基礎速度 × 0.45）移動
  - 硬直期間主動遠離球體著陸點
  - 拾球冷卻 0.7 秒
- 搶奪後球體著陸方向偏向搶奪者（遠離被搶者）
- 搶奪著陸距離增大至 80–140px（原本較短）
- 解決 AI 被搶奪後立即奪回球體的問題

## v1 — 初始版本
**變更類型：** 全新建立

### 核心遊戲
- HTML5 Canvas 2D 遊戲，600×600 邏輯單位，支援裝置像素比縮放
- `requestAnimationFrame` 遊戲迴圈，delta-time 更新
- 遊戲時長 180 秒（3 分鐘）

### 遊戲規則（9 項）
1. 場地內爭奪球體
2. WASD 移動，空白鍵執行動作
3. 攜帶球體進入己方得分區獲得 +1 分
4. 持球超過 10 秒未得分扣 1 分
5. 拋棄球體後 10 秒內無人拾取扣分
6. 可搶奪對手手中的球體
7. 場地內有隨機障礙物
8. 四角設有得分區（隨機分配）
9. 遊戲結束後顯示勝負

### 技術實現
- 圓形-矩形碰撞檢測與解析
- Web Audio API 音效系統（拾取、得分、搶奪、倒計時、犯規）
- 粒子系統視覺回饋
- 倒計時系統（Ready → Get Set → Go）
- HUD 顯示：雙方分數、倒計時、球體狀態
- 響應式設計，支援行動裝置觸控
- 深色主題，支援 `prefers-color-scheme` 偵測
- Google Fonts（Russo One、Exo 2）
